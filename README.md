# lesson-72-sass-variables — Картка ігрового предмета

Урок 72: **SASS: змінні, nesting** (рівень 1).

## Що зроблено

Картка предмета **«Меч Тіней»** (вигаданий предмет з RPG): SVG-іконка меча,
назва, тип, опис, рідкісність, ціна, кнопка «Купити».

Sass налаштування успадковано з уроку 71 (встановлювати повторно не треба):
`npm install` → `npm run watch:css`, а вивід — `css/main.css`.

## Вимоги уроку — як виконані

- **≥ 7 змінних** — палітра (`$color-magic`, `$color-magic-dark`, `$color-magic-soft`, `$color-card`, `$color-card-light`, `$color-text`, `$color-text-soft`, `$color-gold`) + відступи/скруглення (`$padding`, `$gap`, `$radius`, `$radius-btn`).
- **Змінні для кольорів, відступів і заокруглення** — так, див. вище.
- **Один математичний вираз зі змінною** — `$radius-inner: math.div($radius, 2)` (половина від базового скруглення).
- **Всі елементи оформлені через nesting** — стилі вкладені всередину `.item-card`.
- **`&__title`, `&__price`, `&__button`** — елементи через `&`. (Ціни елемент називається `__price`, бо в HTML ціна — `<span class="item-card__price">`.)
- **`&:hover`** — кнопка підсвічується й трохи підіймається.
- **Модифікатор `&--legendary`** — `.item-card--legendary` додає золоту рамку + світіння.

## ⭐ Бонус-експеримент

У README вище написано і перевірено: **змінюю одну змінну `$color-magic` —
і одразу змінюються назва предмета, рамка картки і кнопка** (колір був у трьох
місцях, а значення — в одному).

Спробуй: у `scss/main.scss` заміни `$color-magic: #8e7cf5;` на
`$color-magic: #4caf50;` і збережи — все перекраситься само.
